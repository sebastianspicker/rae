# Deprecation Strategy

Source repositories should not be deprecated until the umbrella has better docs, equivalent verification, and stable imported modules.

## Thesis validation

This page validates the migration claim that deprecation is a publication and
operator-reliability decision, not just a repository cleanup step.

## Interpretation limits

- equivalent verification and documentation can be hard to prove across unlike
  repos and workflows
